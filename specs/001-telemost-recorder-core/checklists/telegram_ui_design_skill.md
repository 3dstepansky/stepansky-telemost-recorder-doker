# Telegram UI Design System & n8n Integration Guidelines

Этот документ определяет стандарты и правила проектирования профессионального пользовательского интерфейса Telegram-ботов, интегрируемых через n8n. Руководство служит в качестве прикладного навыка (проектирования UI) для построения эстетически безупречных, структурированных и устойчивых к ошибкам интерфейсов взаимодействия.

---

## 1. Базовые принципы визуального стиля

*   **Структурированность и сканируемость:** Любое сообщение от бота должно легко восприниматься «по диагонали». Каждая секция отделяется тематическим эмодзи, заголовком и горизонтальным разделителем.
*   **Использование HTML Parse Mode:** Вместо нестабильного `Markdown`/`MarkdownV2` (который крашится при отправке символов `.`, `_`, `-`, `!`), для всех текстовых полей используется `HTML`.
*   **Иерархия шрифтов:**
    *   `<b>ЗАГОЛОВОК СЕКЦИИ</b>` — заглавные буквы, полужирный шрифт.
    *   `<i>Инструкции/Примечания</i>` — курсив для второстепенного текста, подсказок или статусов.
    *   `<code>данные</code>` — моноширинный шрифт для любых параметров, которые пользователю может потребоваться скопировать (ID, пути, пароли, даты).
    *   `<pre>код/логи</pre>` — блочный моноширинный шрифт для длинных текстов, логов или фрагментов транскриптов.

---

## 2. Разделители и структура дерева

Для визуального разграничения иерархических списков и параметров используются символы псевдографики:

*   `━━━━━━━━━━━━━━━━━━━━━━` — Горизонтальная черта для отделения заголовка от контента.
*   `├` — Узел ветвления списка (параметр в середине блока).
*   `└` — Терминальный узел списка (последний параметр блока).
*   `▪` или `🔹` — Маркеры списков возможностей.

---

## 3. Цветовая палитра эмодзи (Статусы)

Используйте эмодзи строго по назначению для интуитивного восприятия статуса системы:
*   🟢 / 🔴 — Активные процессы, запуск/остановка записи.
*   ⏳ / 🔄 — Длительные операции (обработка ИИ, загрузка в облако, транскрибация).
*   ✅ — Успешное выполнение, сохранение конфигурации.
*   ⚠️ — Предупреждения, некритичные проблемы (лимиты, таймауты).
*   ❌ — Критические сбои, ошибки подключения, отказ API.
*   ⚙️ — Секции настроек, администрирование.
*   🧠 — Функции ИИ, аналитика, генерация саммари.
*   📂 / 📋 — Файлы, списки встреч, архивы.

## 4. Спецификация макетов сообщений (Templates)

### А. Главное меню / Приветствие
```html
🤖 <b>Телемост Рекордер</b> • Главное меню
━━━━━━━━━━━━━━━━━━━━━━
Приветствуем! Я ваш персональный ассистент для автоматической записи и аналитики онлайн-встреч в Яндекс.Телемост.

<b>Основные возможности:</b>
🔹 <b>🔴 Запись встреч:</b> Подключение к комнате, запись звука и видео.
🔹 <b>🧠 Аналитика и ИИ:</b> Полная расшифровка и интеллектуальное саммари.
🔹 <b>☁️ Интеграция:</b> Автосохранение записей на ваш Яндекс.Диск.

Выберите нужный раздел ниже:
```

├ 👤 Имя в комнате: <b>${BOT_NAME}</b>
└ 📅 Запущено в: <code>${TIME}</code>

Вы можете в любой момент остановить запись, нажав на кнопку ниже.

## 5. Проектирование клавиатур (UX n8n)

1.  **Главное и контекстные меню (Reply Keyboard):**
    *   Кнопки главного меню должны быть структурированы по строкам.
    *   Рекомендуемая сетка:
        *   Строка 1: `[🔴 Запись встреч]` и `[🧠 Аналитика и ИИ]`
        *   Строка 2: `[⚙️ Настройки]` и `[ℹ️ Помощь]`
    *   Все контекстные подменю обязаны содержать кнопку `[🔙 Назад]` во избежание тупиковых состояний пользователя.
    *   Всегда используйте параметр `"resize_keyboard": true` для уменьшения размера кнопок до компактного на мобильных устройствах.
2.  **Интерактивные кнопки сообщений (Inline Keyboard):**
    *   Используются для мгновенных контекстных действий (например, `⏹ Остановить запись`).
    *   Параметр `callback_data` должен быть коротким (до 64 байт) и иметь четкий префикс, например: `stop_${meeting_id}`.
3.  **Запрос ввода (Force Reply):**
    *   Используется для сбора текстовых настроек (имя бота, доступы).
    *   Включайте параметр `"force_reply": true` и `"selective": true` при отправке запроса, чтобы клиент Telegram автоматически открывал поле ввода с ответом на сообщение-инструкцию бота.
